# Log timestamp filter parity contract

The native companion covers the public log timestamp module at PM4Py 2.7.22, pinned commit `0715c31f3f1d85924107d6aa5329806db69df899`. It is implemented from retained public observations, without reference implementation inspection. Existing timestamp convenience functions remain separate.

The public surface comprises thirteen functions: seven log filters, four trace predicates, and two generic stubs that raise the observed `Exception`. The native interface is `include/minera/log_timestamp_filter.hpp`. Bounds and selectors use ordinary typed `EventAttribute` values; the options retain both the literal timestamp selector and its public enum-key alternative. The intersecting wrapper's observed literal-only lookup is preserved. Only starting and completing use the positive control. Raw predicates do not parse string bounds; filter wrappers parse the public space-separated datetime form.

Event and bound datetime normalization replaces timezone information with UTC, preserving wall-clock fields. It does not convert an offset timestamp to its original UTC instant. Inclusive endpoint comparisons preserve empty-trace behavior, reversed intervals, first/last-only checks, contained-filter lazy final lookup, intersecting-filter eager endpoint reads, missing-key precedence, typed errors, and NaT comparisons. Attribute matching checks attribute presence and value equality before reading an event timestamp. Whole-trace filters preserve context; the attribute-in-timeframe filter drops log properties as observed.

`filter_log_timestamp_events(EventLog&)` deliberately preserves the public converter's source mutations. After bounds parse, it injects case-prefixed trace attributes into all source events, including before a later timestamp or regrouping error. Existing case-prefixed cells are overwritten in their original dictionary position. Selected events are regrouped by the canonical `case:concept:name` cell, case-prefixed fields become trace attributes and are removed from returned events, duplicate equal case identifiers merge, and reconstructed trace properties are empty. The const overload explicitly makes a source copy. No canonical identifier is invented, and public case-id parameters do not redirect this converter. Product import preparation must remain distinct from these native semantics.
