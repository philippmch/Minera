# Log variants filter parity contract

This native companion implements the seven public functions of `pm4py.algo.filtering.log.variants.variants_filter` from PM4Py 2.7.22, pinned commit `0715c31f3f1d85924107d6aa5329806db69df899`. Only public signatures, docs, enums, complete public calls and opaque module hashes were used. Reference implementation source, AST, bytecode and private state were not inspected. The closed convenience `filter_log_variants_percentage` is unchanged; the new typed cumulative entry point is `filter_log_variants_cumulative`.

The native API in `include/minera/log_variants_filter.hpp` exposes membership, cumulative coverage, minimum individual coverage, maximum individual coverage, top-k, dictionary-percentage filtering and automatic threshold finding. Criteria and activity selectors use typed ordinary `EventAttribute` values. `LogVariantsDictionary` retains ordered typed variant keys, full trace values, and ordinary non-trace values for public length diagnostics. A separate typed dictionary-admission carrier retains tuple keys that the generic string-key attribute dictionary cannot encode.

Variant keys are tuples. A collection of tuple sequences matches; the documented list-of-lists shape does not match tuple variants. A list of comma strings also does not match; commas inside one activity remain distinct from multiple activities. Raw string admission raises its observed tuple-membership error. Empty tuples identify empty traces. Membership, minimum/maximum individual coverage and top-k honor positive polarity; cumulative coverage ignores it. Enum and literal activity selectors agree in the retained calls, and the decreasingFactor parameter is inert for these public wrappers.

Returned logs retain complete log and trace context and properties. Membership and individual-coverage results emit variant groups in first-encounter order, preserving trace order within each group. Top-k ranks by descending count and descending typed key for admission, then emits first-encounter groups. Cumulative and dictionary-percentage results emit sorted variant groups, retaining frequency ties beyond the cumulative threshold. Top-k keeps Python-style negative slices, integer/bool controls, and the observed clamp-before-slicing behavior. Automatic thresholds use strict successive-count comparisons and return a ratio over the supplied log length. Ordinary typed activity values, missing cells, unhashable activities, NA ambiguity and typed comparison diagnostics retain their observed behavior.
