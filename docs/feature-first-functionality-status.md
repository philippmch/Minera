# Functionality inventory

The pinned catalogue contains 86 algorithm families and 387 modules. The Feature60 source audit found existing application surfaces for 71 families and specific missing inputs, operations or controls in 15 families. Those figures describe static availability, not full behavior or parameter coverage.

Strict parity remains 46/86 packages and 199/387 modules, with 228 incomplete coverage units. Feature delivery does not promote these strict counts.

This is the frozen inventory before the original Declare workbench. Later delivery reports record completed gaps without rewriting this historical audit. Feature61 delivers original offline Declare conformance and playout; Feature62 delivers original log-skeleton conformance and standalone diagnostics. Feature63 delivers eighteen original-footprints comparison, metric, diagnostic, utility and tree-decoration operations. Feature64 delivers caller-supplied original genetic causal-matrix conversion. Feature65 delivers all five independent original embedding operations, native filtering/full filtered EventLogs and keep_cases. Feature66 delivers independent original weighted-language EMD evaluation/scalar distance, original EventLog derivation and all four real finite table callback slots. Feature67 delivers original OCPN/object-centric causal-net playout across all four public operations and eighteen native options, with full stored state and byte-safe artifacts. Exact literal controls are next in Feature68; browser verification and strict gates remain open.
